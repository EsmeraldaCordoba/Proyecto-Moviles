# NutriStatus

Idea de Proyecto: Sistema de Gestión de Citas y Progreso Nutricional

Integrantes: Esmeralda Gonzalez Cordoba y Brandon Conejo Quirós

Descripción de la idea:

NutriStatus es una aplicación móvil diseñada para facilitar la interacción entre pacientes y nutricionistas. El sistema permite a los pacientes gestionar sus citas médicas de forma autónoma y llevar un registro visual de su plan de alimentación. El objetivo es optimizar el tiempo de consulta y ofrecer un seguimiento cercano del progreso del paciente mediante un registro fotográfico y control de agenda.

Funcionalidades principales:

CRUD: Creación, lectura, actualización y eliminación de citas nutricionales (agendar, ver historial, reprogramar fecha/hora y cancelar cita).

Lista con filtros personalizados: Visualización del historial de citas con la opción de filtrar por estado (Pendientes, Completadas, Canceladas) o filtrar el directorio de especialistas por enfoque (Nutrición Deportiva, Control de Peso, Nutrición Funcional para el Equilibrio Hormonal).

Acceso a cámara o galería: El paciente puede tomar fotografías de sus platillos diarios o subir fotos de su progreso físico desde la galería para que el nutricionista las evalúe en la siguiente consulta.

Dialog: Ventanas emergentes de confirmación, por ejemplo: "¿Está seguro que desea cancelar su cita con menos de 24 horas de antelación?" o "Cita agendada exitosamente".

Mapa: Una vista interactiva que muestre la ubicación exacta de la clínica para que los pacientes puedan trazar su ruta de llegada.
